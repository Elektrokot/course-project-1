# Финансовый анализатор транзакций

## Описание

Этот проект представляет собой Python-приложение для анализа финансовых транзакций, загружаемых из XLSX-файлов. Приложение предоставляет интерактивную консольную утилиту для поиска, фильтрации, агрегации и отображения информации о транзакциях, а также получения внешних данных (курсы валют, цены акций).

## Установка

1.  Убедитесь, что у вас установлен Python >= 3.13 и Poetry (или pip).
2.  Склонируйте репозиторий.
3.  Установите зависимости:
    ```bash
    poetry install   # или: pip install -r requirements.txt (если используется pip)
    ```

### Зависимости

- `pandas >= 3.0.0` — для работы с данными в табличном формате.
- `openpyxl >= 3.1.5` — для чтения XLSX-файлов.
- `requests >= 2.32.5` — для HTTP-запросов к API (ЦБ РФ, Alpha Vantage).
- `environs >= 14.5.0` — для работы с переменными окружения.

## Настройка

### Файл транзакций
1. Убедитесь, что файл `data/operations.xlsx` находится в соответствующей директории.
2. Формат файла должен включать следующие столбцы:
   - `Дата операции` — `DD.MM.YYYY HH:MM:SS`
   - `Статус` — `'OK'`, `'Отмена'` и др.
   - `Сумма операции`, `Валюта операции`
   - `Сумма платежа`, `Валюта платежа`
   - `Категория`, `Описание`, `Кэшбэк`, `Округление на инвесткопилку`, и др.
3. В проекте используется `PATH_TO_OPERATIONS = PATH / "data" / "operations.xlsx"` (настраивается в `config.py`).

### Пользовательские настройки
- Создайте файл `user_settings.json` в корне проекта (если хотите задать свои валюты/акции):
  ```json
  {
    "user_currencies": ["USD", "EUR"],
    "user_stocks": ["AAPL", "AMZN", "GOOGL", "MSFT", "TSLA"]
  }
  ```

### API-ключи (опционально)
- Если планируется использование внешних API, укажите ключи в переменных окружения или в файле `.env`:
  ```
  API_KEY_ALPHAVANTAGE=ваш_ключ_здесь
  ```

## Запуск

### Интерактивный режим

```bash
python main.py
```

После запуска появится меню:

```
--- Меню ---
1. Главная страница (main)
2. Страница событий (events_page_data)
3. Простой поиск (simple_search)
4. Поиск переводов физ.лицам (search_transfers_to_individuals)
5. Поиск по телефонным номерам (search_transactions_by_phone_numbers)
6. Инвесткопилка (investment_bank)
7. Анализ выгодных категорий кешбэка (analyze_cashback_categories)
8. Траты по категории (spending_by_category)
9. Траты по дням недели (spending_by_weekday)
10. Траты по рабочим дням (spending_by_workday)
0. Выход
------------
```

После выбора пункта приложение запросит нужные параметры и сохранит результат в `result.json`.

### Программное использование

Вы можете импортировать функции и использовать их напрямую:
```python
from src.utils import load_transactions_from_xlsx, get_currency_rates
from src.services import simple_search, investment_bank

df = load_transactions_from_xlsx("data/operations.xlsx")
results = simple_search("кафе", df.to_dict('records'))
```

## Функциональность

### 📊 **Главные отчёты и страницы**
- **Главная страница (`main`)** — приветствие, данные по картам (расходы/кешбэк), топ-5 транзакций, курсы валют, цены акций.
- **Страница событий (`events_page_data`)** — фильтрация по дате и периоду (`D`, `W`, `M`, `Y`, `ALL`) с группировкой доходов/расходов.

### 🔍 **Поиск и анализ**
- **Простой поиск** — по ключевому слову в описании или категории.
- **Переводы физ.лицам** — поиск транзакций в категории `Переводы`, где в описании есть паттерн `"Имя Б."`.
- **Телефонные номера** — поиск транзакций с мобильными номерами в формате `+7 XXX XXX-XX-XX` или `+7 XXX XXX XX XX`.

### 💰 **Аналитика**
- **Инвесткопилка** — сумма, накопленная за месяц через округление (из столбца `Округление на инвесткопилку`).
- **Кешбэк по категориям** — потенциальный кешбэк при выборе категории как повышенной (`10%` от суммы).

### 📈 **Отчёты**
- **Траты по категории** — последние 3 месяца от указанной даты.
- **Траты по дням недели** — агрегированная сумма расходов за период.
- **Траты по рабочим дням** — расходы только в понедельник–пятница.

## Известные особенности и замечания

- Даты в формате `DD.MM.YYYY HH:MM:SS` (обязательно с двузначными компонентами).
- Суммы в рублях — используются как числа с плавающей точкой; запятая в Excel заменяется на точку при загрузке.
- Отрицательные значения → расходы, положительные → доходы (в столбце `Сумма операции`).
- Если кэш по акциям существует и сегодняшняя дата совпадает — используются закешированные данные.
